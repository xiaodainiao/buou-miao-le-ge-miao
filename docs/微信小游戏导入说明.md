2. 点击导入项目，目录选择 F:\CodexRecord\WeChatCodex\小宝布偶猫（含 project.config.json 的根目录）。
3. AppID填写 wxf790ae3ae8fcb811，项目类型应识别为小游戏；不使用普通小程序模板，不启用云开发。
4. 导入后点击编译，检查首页、三关、图鉴及玩法说明。
5. 如提示没有权限，需由该AppID管理员在后台把当前登录微信加入开发者；不能通过改代码解决账号权限。
6. 点击预览生成二维码，手机测试9张、216张及1000张关卡，以及前后台切换、音效和存档。
