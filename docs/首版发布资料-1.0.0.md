## 游戏简介
《布偶瞄了个喵》是一款猫咪主题的休闲消除游戏。玩家选择未被上层卡牌遮挡的图片，收集三张相同图片进行消除，在有限槽位中规划选牌顺序，完成三个由易到难的关卡。

## 各主要场景描述
《布偶瞄了个喵》整体采用奶油色和柔和绿色的温馨风格。主界面展示小宝的布偶猫插画、游戏名称、开始游戏、关卡选择、卡牌图鉴及玩法说明。游玩界面由不规则叠放的图片卡牌、七格收集槽、临时寄存区和道具按钮组成。卡牌分为小宝日常、猫咪美食、温馨猫窝三个系列。通关、失败及暂停时展示对应操作面板。

## 整体玩法设计
玩家点击没有被更高层卡牌实际重叠遮挡的卡牌，将其移入七格收集槽。收集槽内出现三张完全相同的图案时自动消除；被上层牌压住的下层牌暂不能选择，移开实际遮挡后即可选择，旁边相邻的牌不会阻挡。收集槽占满且未触发消除时本局失败。第一关有九张无叠层明牌，第二关有二百一十六张不规则叠牌，第三关恰好有一千张，其中九百九十九张参与三消，另有一张金边“福”奖励牌。奖励牌同样需解除遮挡，点击后直接收集而不占槽位。清空全部卡牌及寄存区并收集奖励牌后通关。

## 道具系统说明
撤回、洗牌、寄存和复活每局各可免费使用一次。撤回仅恢复最近一次尚未触发消除的选牌操作。洗牌保留剩余普通牌数量及布局，并重新安排图案以提供可通关路径，寄存区非空或槽位状态不满足条件时不可使用。寄存将收集槽最前面最多三张牌暂存，玩家可点击取回。失败时寄存区为空且复活尚未使用，可将槽内最前面最多三张牌寄存后继续。奖励牌直接收集，不能撤回此次奖励收集。
