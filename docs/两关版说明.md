# 两关版

第一关：18张牌、3种图案、2层，学习三张消除。
第二关：216张牌、全部24种图案、不规则多层主牌堆192张，加左右各12张储备牌。解答序列交错配对，需要规划收集槽。

某张牌没有被任何更高层且实际重叠的牌压住，就可以选择。仅在旁边相邻或处于同一层不会阻挡。上层移走后，下层立即重算并亮起。

生成器保证至少有一条不使用道具的通关路径；极难是当前最高难度配置，实际难度尚需真人试玩。

采用独立v4存档及进度键，旧10关记录留在原有键中，不自动读取。声音偏好沿用。微信真机与开发者工具验收仍未完成。

## 不规则遮挡 v5
