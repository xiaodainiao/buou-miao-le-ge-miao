# 三关版 v6

- 第一关：9张明牌、3种图案、无叠层，简单教学。
- 第二关：216张、24种图案、不规则多层遮挡，左右各12张储备牌。
- 第三关：恰好1000张，其中999张普通三消牌加1张小宝奖励牌，左右各48张储备牌。1000不是3的倍数，所以奖励牌采用已确认的歪头小宝图片加金边及“福”字标记，未引入新素材。奖励牌同样需先解除遮挡，点击后直接收集、不占槽位，不计入三消组数；不能撤回这次奖励收集。必须收集奖励牌并清空普通牌才能通关。

性能：遮挡关系按几何布局缓存，生成通关顺序使用依赖图；完全被一张上层牌覆盖的牌不参与绘制。图片全部加载后统一绘制，微信端连续操作的存档合并为200毫秒一次，切后台或退出立即保存。

新版进行中的牌局使用v6键，旧版牌局不自动载入；进度沿用，已通关原第二关的玩家直接开放第三关。

本机逻辑性能测量不代表微信手机实测，仍需开发者工具及真机验证。
